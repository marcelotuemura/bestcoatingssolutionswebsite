# Project photography inbox

Owner-uploaded project photos, compressed for the repo.

- Source folders on `main` were `chris craft/` and `gold Axopar/` (JPEG WhatsApp / camera originals).
- Files here are web-optimized **WebP**, max edge **1600px**, EXIF orientation applied, metadata stripped.
- These are **not published** on the marketing site until approved and wired.
- Drop additional albums as `data/photography/<project-slug>/`.

Do not commit multi‑MB camera originals to the repo root. Keep masters offline or in private storage; commit only compressed web exports.
