# Media Catalog (08_Reports sync)

Phase 2 Interactive Media Library reads these files as the **source of truth**:

| File | Purpose |
|------|---------|
| `media_catalog.json` | Full asset catalog |
| `projects_report.json` | Project summaries |
| `duplicates_report.json` | Exact / near duplicate groups |
| `search_index.json` | Optional search tokens |
| `MEDIA_INDEX_SUMMARY.md` | Human summary |

## Syncing real reports

Copy from the local media vault reports folder:

```bash
cp "/Users/marcelotomiouemura/Desktop/Best Coatings Solutions Media/08_Reports/"*.{json,md,csv,html} \
  ./data/media-catalog/
```

Or set `MEDIA_CATALOG_DIR` to the absolute `08_Reports` path.

## Fixtures

If reports are missing, the app falls back to a deterministic fixture catalog
(`isFixture: true`) generated by `lib/media-library/fixture-catalog.ts`.

Regenerate committed fixtures:

```bash
pnpm exec tsx scripts/generate-media-catalog-fixtures.ts
```

**Never** place original binaries here. Catalog JSON only.
